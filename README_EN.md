# RackTop

Server monitoring, remote terminals, and team collaboration in one workspace.

**[Download and install](https://136.0.110.161/downloads/)** · **[Open the team workspace](https://136.0.110.161/)** · **[User guide](docs/WORKSPACE.md)** · [简体中文](README.md)

## Install

Choose your computer on the download page. Use the prepared installer; no source build or development tools are required.

| Computer | Installer |
| --- | --- |
| Ubuntu 20.04, Intel / AMD 64-bit | Flatpak compatibility kit |
| Ubuntu 22.04, Intel / AMD 64-bit | DEB package |
| Mac with an M-series chip | Apple Silicon DMG |
| Mac with an Intel processor | Intel DMG |

**Version 2.5.0 and the unified installer are being prepared and have not been published.** The download page currently offers the 2.2.2 development compatibility kit for Ubuntu 20.04 and the 2.2.1 pre-release for Ubuntu 22.04 / Mac. See the [installation and upgrade guide](docs/DOWNLOADS.md) (Chinese).

## Get started

- **Manage servers:** Open the desktop app, add an SSH connection, inspect GPU / CPU activity, use terminals, synchronize projects, and manage jobs.
- **Work with your team:** Sign in to the online workspace to manage equipment and QR labels, reserve compute resources, and write weekly reports.
- **Find instructions:** [Linux](docs/LINUX.md) · [Mac](docs/MACOS.md) · [Equipment](docs/EQUIPMENT.md) · [Resource sharing](docs/SHARING.md).

Quit the old app before upgrading. Upgrades using the same installation format retain existing data. DEB and Flatpak use different data directories; back up before changing formats.
