## 实现与权限

设备目录显示总数和 available / in_use / maintenance / retired 四种状态数量，通过原生展开控件展示公司、类别、位置分布。统计独立于搜索及公司、状态筛选，打开目录、返回目录和主动刷新时读取，无定时自动刷新。加载、失败重试和会话变化均有相应状态处理。

`GET /api/equipment/stats` 在设备 UUID 路由之前匹配，拒绝查询参数；服务端在同一只读事务内聚合全部可见设备，不读取照片内容。成员及普通管理员仅本公司，超管包括未分配的历史设备。四种状态总是含零值，分组只返回实际存在的公司、类别及位置并保留历史值，不暴露设备名称、编号、人物或备注。没有新增图表依赖或数据库迁移。
