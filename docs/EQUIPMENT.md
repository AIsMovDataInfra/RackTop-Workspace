# 硬件设备管理

设备管理与团队预约使用同一在线服务和账号。网页地址：[设备管理](https://136.0.110.161/equipment)。RackTop 侧栏「密钥管理」与「日志」之间的「设备管理」会在浏览器打开该页面，手机也可直接使用，无需安装 RackTop。

## 三步使用

1. **录入设备**：登录后选择「新增设备」，只必填设备名称。分类、型号、序列号、责任人、位置、状态和备注按需填写。
2. **打印标签**：打开设备详情，显示二维码并打印标签，贴到对应设备。标签上保留设备名称、编号和型号，二维码指向该设备的固定页面。也可以下载二维码图片另行排版。打印后先用手机试扫确认。
3. **扫码登记**：手机相机或扫码工具识别二维码，打开设备详情；无需登录即可查看。点击「领用登记」并登录，责任人默认填当前姓名，状态默认为使用中；确认或修改位置后保存。也可通过编辑设备修改其它信息。

一个二维码对应一件设备，编号和链接由系统分配。修改责任人、位置或名称不会改变链接，不用重新贴码。二维码本身保存固定网页地址，设备资料保存在服务器，扫码读取最新内容；二维码图片在当前浏览器生成，不发送到第三方制码服务。未联网时无法读取最新档案。

## 设备档案

支持名称、分类、型号、序列号、责任人、位置、状态和备注；状态为可用、使用中、维修中和已退役。列表可搜索和按状态筛选。设备不用了可改为已退役，原标签仍能查到记录。

已登录成员可以录入和维护设备，页面记录最近 30 次创建或修改，包括修改人、时间及字段变化。两个人同时编辑时，后保存者收到版本冲突提示，输入保留，读取最新资料后再确认保存，避免悄悄覆盖他人的修改。

## 账号

用户名和密码只要求非空，支持中文、英文及短密码，不要求特定字符组合。用户名忽略两端空格和大小写，仍不可重名；密码按原始内容校验，新密码不能只有空白。姓名是单独的固定显示名，保留唯一性与 1–60 字符要求。现有账号和密码继续可用。

## 使用边界

这是团队共享设备台账，扫码页面可以公开查看设备资料和责任人、位置，已登录成员可以编辑。首版不包含库存采购、审批、附件上传、自动识别硬件或控制设备；设备领用登记也不会自动授予服务器 SSH 权限。

网站仍以公网 IP 提供服务。二维码包含此站点地址，将来迁移地址时，应保留旧地址转发到原设备页面，或重新打印标签。不要手动改设备编号或复用同一个标签到另一件设备。

设备档案与预约、账号存储在同一个 SQLite 数据库的独立表中，沿用现有一致性备份。升级不会覆盖已有预约与账号。实际发布与验收结果以当前 Release 和交付记录为准。
