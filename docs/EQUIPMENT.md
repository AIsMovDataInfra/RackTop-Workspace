# 硬件设备管理

设备管理与团队预约使用同一在线服务和账号。网页入口为[设备管理](https://136.0.110.161/equipment)，手机和电脑浏览器均可使用，无需安装 RackTop。桌面侧栏「密钥管理」与「日志」之间的「团队工作台 → 设备管理」会打开该网页。

本页说明 **2.4.0 在线版** 的设备总体统计与现有台账功能；统计已于 2026-09-11 20:03:06（UTC+8）上线，见[2.4.0 验证记录](VERIFICATION_2_4_0.md)。标签 PDF/PNG 导出和云端自动备份继续保留。超级管理员自身没有公司归属，可跨公司查看、登记和调整资产；设备仍必须归属于四家公司之一或处于待分配状态。网页更新无需安装新版桌面客户端。

## 设备总体统计

目录上方的「设备统计」显示总数，以及可用、使用中、维修中、已退役的数量。点击「查看公司、类别与位置分布」可展开各项明细；没有设备的分组不列出，历史公司为空时显示待分配，旧类别和位置原样保留。

统计覆盖当前账号有权查看的全部设备：超级管理员跨公司，普通成员和资源管理员仅本公司。下方搜索、公司和状态筛选只改变目录，不改变总体统计；状态按已保存的设备状态计算，不根据使用人文字推断。打开目录、从详情返回或点击「刷新」时重新读取，统计失败可点击「重试统计」。页面不定时自动刷新，其他人新增或修改后可主动刷新查看。

## 登录后查看和登记

设备列表、详情、照片、修改记录，以及服务器资源和预约排期，都需要登录团队账号；普通成员和资源管理员还需由超级管理员分配公司。新注册或升级后未分配公司的成员会看到待分配页面，不能跳过检查。未登录时只显示登录／注册界面；直接访问二维码地址或旧照片地址也不能跳过登录。扫码后登录会继续打开原设备页面。

新网页使用一个成员名称和密码注册，不需要邮箱或另外的用户名；名称支持中英文，去除两端空白后非空即可，不另设长度或字符格式限制、不做 Unicode 规范化，且不可重名。旧账号继续用原用户名登录，原姓名与 UUID 保留。密码不裁剪空格，新密码不能全为空白；旧密码继续兼容。

登录界面的「记住登录」选中时保持 360 天，未选中时为 8 小时；独立桌面设备登录仍为 30 天。退出会注销当前网页登录并清除页面中的业务资料；修改密码会撤销旧网页会话和桌面设备登录。用户名、负责人或使用人姓名本身都不是授权凭据。忘记密码可在登录页提交申请，再联系超级管理员核实身份并设置新密码；不会发送邮件或自动消息。账号管理、公司分配和运维恢复见[团队账号说明](TEAM_ACCOUNTS.md)。

## 新建设备与固定编号

普通成员完成登录和公司分配后可点击「新增设备」；超级管理员登录后可直接新增并选择资产所属公司。填写设备名称，并选择类别和位置。负责人默认填入当前成员姓名，可修改或清空；型号、使用人和备注按需填写，状态默认为可用。

设备编号由服务器自动生成，是从 `00000001` 开始递增的八位数字，创建和编辑时均不能手动指定。多人同时创建不会取得相同编号，重启或设备退役不会让已使用的编号被重新分配。

旧设备会按创建顺序分配八位编号；以前自由填写的序列号保留在详情的「原序列号」，不会直接丢弃。原 `RT-…` 编号和设备 UUID 也保留。设备名称、负责人、使用人、位置或照片变化都不会改变设备链接。

## 资产所属公司

每件设备有独立的「公司名称」，可选 **A公司、B公司、C公司、西浦**。目录行也明确显示公司，避免只凭负责人推断归属。普通成员新建和编辑时也能看到公司下拉，但只能选择自己已分配的公司；服务端拒绝伪造其他公司。超级管理员可选择任意公司并跨公司调整资产。

设备公司不是实时跟随登记人的字段：员工调公司、其他成员编辑、领用或归还，都不会把设备迁移到操作人的公司。旧设备的公司保留为空并显示「待分配」，由超级管理员核实后补齐，不猜测归属，不改变八位编号和二维码。未分配公司的旧设备只有超级管理员可见和维护，分配后才向对应公司成员显示。

超管的公司筛选固定显示四家公司及设备数量，零设备公司也可选择，并有「全部公司」「待分配公司」选项；选择空公司会显示对应空状态。普通成员只显示自己公司，筛选不可改为其他公司。超管在具体公司筛选下新增设备时会预选该公司，全部公司或待分配筛选不自动猜测归属。

成员只可查看和维护本公司设备、照片及可见修改记录，跨公司设备详情返回不可访问。设备移交后，旧公司的修改记录不会显示给新公司普通成员；超管保留完整历史。完整员工账号名册只向超级管理员开放。

## 类别与位置

新建时必须选择以下选项，编辑时也按相同选项校验：

| 项目 | 可选值 |
| --- | --- |
| 类别 | 机械臂、台式主机、显示屏、摄像头模组、实验物料、小推车、夹爪 |
| 位置 | 上海、太仓 |

旧记录中其他类别或位置会原样显示，并标记需要重新选择。系统不会猜测它属于哪个新选项；下次编辑、领用或归还保存前，需要选择正确的类别和位置。单独上传或删除照片不要求同时修改旧类别、位置。

## 负责人、使用人与归还

**负责人**表示由谁负责这件设备，**使用人**表示当前由谁使用，两者独立。

点击「领用登记」时，使用人默认填当前登录成员姓名，状态默认为使用中；核对类别、位置后保存。领用不会自动把负责人改成使用人。点击「归还登记」会清空使用人，并将状态改为可用，负责人保持原值；也可单独在编辑中调整这些字段。

任何已登录且已分配公司的成员都可维护本公司实物台账，字段中的姓名不限制谁能编辑；只有超级管理员可跨公司调整设备。资源目录仍由管理员管理，预约仍只有本人或管理员可修改、取消或提前结束，设备领用不会授予 SSH 登录或 GPU 操作权限。

## 拍照、上传与更换

每台设备可保存一张照片。在详情中点击「拍照」调用设备支持的拍摄入口，或选择已有照片；选择后先预览，再点击「保存照片」。手机浏览器是否直接打开相机取决于设备和权限，也可以从相册选择。支持 JPEG、PNG、WebP；HEIC 请先导出为 JPEG。

网页接受最多 20 MiB、2400 万像素的原始照片，在本机自动缩小和压缩后上传。服务器会再次校验真实图片内容、方向和大小，去除 EXIF 等元数据，最终保存最长边不超过 1600 像素、大小不超过 512 KiB 的 JPEG。服务器不保存原始大图。

设备目录直接显示已有照片的小缩略图，没有照片时显示占位图，便于按外观寻找实物；缩略图仍须同公司会话授权，不公开原图。已有照片可以更换，取消预览不会改变已保存照片。点击「删除照片」并确认，仅删除照片，设备档案和二维码保持不变。照片需要成员登录并通过公司检查才能读取，服务端不允许公开缓存。

照片与文字编辑共用设备版本。两个人同时操作时，旧版本会提示冲突；所选照片或输入保留，读取最新版本后核对再保存或删除。失败的替换不会丢失旧图，压缩期间退出登录或失去公司访问资格，也不会继续保存。

## 二维码标签与记录

打开设备详情的「设备标签」，会显示标题为 **「固定资产标识码」** 的表格，右侧放置二维码，左侧列出：

| 标签字段 | 内容 |
| --- | --- |
| 公司名称 | 设备所属公司；旧设备未指定时显示待分配 |
| 资产编号 | 不可修改的八位数字编号 |
| 资产名称 | 设备名称 |
| 责任人 | 设备负责人；未填写时显示破折号 |
| 使用人 | 当前使用人；空闲未登记时显示破折号 |

标签操作统一为「打印标签」：点击后直接选择 PDF 或 PNG，两种格式都包含完整表格和二维码。PDF 已按标签边界裁剪，页面宽度为 140 mm，高度随文字内容增长，不包含 A4 白边或网页页眉；打开下载的 PDF 后按实际尺寸打印即可。PNG 可作为完整标签图片保存或交给支持图片的打印软件。导出失败时会显示提示，可再次选择格式重试。

手机上表格可左右滑动，长名称会换行。打印后先用手机试扫，再贴到对应设备。

一个二维码对应一件设备，内容为固定的 `/equipment/<设备UUID>` 网页地址。二维码在当前浏览器生成，不发送到第三方制码服务。设备更新后二维码保持不变，扫码可查看最新档案；已经印在纸上的公司、名称或人员变化后，需要重新打印以更新纸面文字。扫码者需要联网、登录团队账号并通过公司检查，才能查看最新档案。不要把同一标签复用到另一件设备。

列表可搜索名称、编号、型号、负责人、使用人等信息，并按状态筛选。状态包括可用、使用中、维修中和已退役；停用设备改为已退役，档案和原二维码保留，没有删除设备的入口。

详情展示最近 30 次有权限查看的创建或修改记录，包括真实操作人、时间和字段变化；照片上传、更换和删除也会记录。版本冲突不会悄悄覆盖另一位成员的修改。

## 数据与备份

设备档案、照片、永久编号分配和修改历史与预约、账号保存在同一个 SQLite 数据库的独立表中。照片是 `equipment_photos` 表内的压缩 JPEG，不需要维护单独的图片目录。

沿用服务的一致性备份脚本即可同时备份设备、照片、编号和历史；不要只复制运行中的 `.sqlite` 主文件而遗漏 WAL。升级迁移在事务内进行，失败会整体回滚，重复启动不会重新编号。恢复完整快照时保留原 UUID 和编号分配，旧二维码仍指向原设备。具体操作见[部署说明](../team-web/deploy/README.md)。

云服务器已配置每 15 分钟自动快照，并保留近期、每日和每月恢复点。2026-09-11 19:50:10（UTC+8）对新增登记执行即时备份并通过新版本独立恢复演练，20:03:53 上线后再次备份验证，包含当时全部 32 台设备和 37 条修改记录，见[本轮验证记录](VERIFICATION_2_4_0.md)。快照与数据库仍在同一服务器，异机备份尚未配置；备份恢复能力及操作边界见[备份运维说明](../team-web/deploy/BACKUPS.md)。

这是按公司隔离的设备台账，本公司成员能看到负责人、使用人、位置、备注、照片和允许的记录，数据库和备份应按团队资料限制访问。当前不包含采购付款、任意附件、自动硬件识别或设备控制。

设备申请在[工作台的申请与领取](WORKSPACE.md#设备申请与领取)中单独提交。员工只得到编号确认，申请正文仅超管可读；超管批准后登记领取，关联现有设备的申请会在同一事务中更新设备使用人和状态，并写设备与申请两套审计。未关联设备的申请不会自动创建资产或采购单，仍需人工落实。

网站当前使用公网 IP。将来更换站点地址时，应保留旧地址到对应设备页面的转发，或重新打印标签。实际手机拍照、实体扫码和纸质打印的兼容性仍需在使用设备上验收。
