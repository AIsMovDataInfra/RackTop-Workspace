发布后可自动选择 Ubuntu 20.04 / 22.04 安装包，下载并校验后安装。已有 Flatpak 会沿用原来的安装范围和资料。

curl --proto '=https' --proto-redir '=https' -fL https://136.0.110.161/downloads/install-racktop.sh -o install-racktop.sh && bash install-racktop.sh

使用普通用户运行。只在安装系统组件时提示管理员认证；无需编译源码。

Ubuntu 20.04

Intel / AMD 64 位电脑 · x86_64

2.2.2 开发兼容版简易安装套件 · 约 472 MiB

下载 Ubuntu 20.04 安装包

解压后运行一个安装命令

  1. 提取压缩包，进入解压后的文件夹。
  2. 在文件夹空白处右键，选择“在终端打开”。
  3. 粘贴以下命令并回车：
    /bin/bash install-racktop.sh
  4. 安装成功后启动：
    /usr/bin/flatpak run com.racktop.desktop

安装命令前不用加 sudo。首次补齐系统组件需要联网和本机管理员密码；应用与运行时已包含在套件中。

查看 Ubuntu 20.04 详细教程

Ubuntu 22.04

Intel / AMD 64 位电脑 · amd64

2.2.1 测试版DEB 安装包

下载 Ubuntu 22.04 安装包 GitHub 备用下载

在下载目录安装

  1. 进入安装包所在文件夹，右键选择“在终端打开”。
  2. 运行以下命令，按提示输入本机管理员密码：
    sudo apt install ./RackTop_2.2.1_linux-amd64.deb
  3. 在应用菜单搜索并打开 RackTop，也可运行：
    racktop

APT 会联网补齐缺少的运行组件。此 DEB 适用于 Ubuntu 22.04 amd64；Ubuntu 20.04 请选对应的兼容套件。

Mac 首次打开

两种 Mac 安装包均采用 ad-hoc 本地代码签名，未经过 Apple 公证。若提示无法验证开发者，确认下载来源后，先尝试打开一次，再到“系统设置 → 隐私与安全性”选择“仍要打开”。

不同 macOS 版本的界面可能略有区别，请参考 Apple 官方打开 App 说明。
